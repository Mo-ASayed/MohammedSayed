
## October 17: warm palette and a manipulable retrieval map

Replaced the dark Hamid-inspired colours with Apricot's ivory, peach and warm brown. The RAG Explore stage now opens with a three-layer map expedition. Users drag questions and passages, adjust retrieval reach, remove outdated policies, and observe a bounded context window feeding a scripted answer. Each layer starts with a brief explanation and a concrete goal. Successful setups reveal the next layer; mistakes explain the actual evidence problem.

The sandbox uses real Euclidean distance in an explicitly simplified 2D space. It does not claim to project the existing six-dimensional vectors. The original synonym/keyword comparison remains available in a collapsed deeper experiment. Keyboard arrows and Shift+arrows support marker movement; pointer capture supports mouse, pen and touch. No login, API, or additional persistence is required.

Validation: production build; 21 unit checks; browser completion of all three layers, wrong-answer feedback, moving sources, metadata filtering, budget constraints, reset, keyboard interaction and narrow layouts. Existing RAG and personal playground browser regressions pass. Screenshots are in test-results/map-quest-*.png.
